# Refal laboratory

Лаборатория переписываний для Ruby Surface / NAM / Radix.

Содержимое:

- swap.ref — минимальный пример сопоставления и перестановки;
- skipWs.ref — удаление начальных пробельных символов;
- ruby-to-spatial.ref — ранний опыт нормализации класса и метода;
- ruby-free-functions.ref — опыт со свободной функцией и прямым вызовом;
- ruby-text-class.ref — минимальный разбор настоящего текста class … end;
- refal.el — минимальный режим Emacs для исходников Refal.

Сборка отдельного эксперимента:

    rlc ruby-to-spatial.ref
    ./ruby-to-spatial

Скомпилированные файлы не входят в репозиторий.
