# Ruby Surface / NAM / Radix / Spatial VM

Исследовательский проект по преобразованию Ruby в минимальную пространственную
вычислительную машину.

## Компоненты

- [`research/`](research/) — семантика Ruby, гипотезы и открытые вопросы;
- [`rewriting/`](rewriting/) — Refal/НАМ-нормализация и переписывание;
- [`radix/`](radix/) — представление программы в Radix-графе;
- [`automaton/`](automaton/) — пространственный операционный автомат;
- [`prototype/`](prototype/) — минимальные сквозные эксперименты.

Компоненты исследуются отдельно. Полный конвейер собирается только после того,
как определены их границы и контракты.
